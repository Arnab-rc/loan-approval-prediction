# Loan Approval Prediction System

An end-to-end Machine Learning project that predicts whether a loan application will be approved or rejected based on applicant financial data.

## Features
* **Data Preprocessing & Imputation:** Handled missing values using Scikit-Learn imputers.
* **Feature Scaling:** Standardized numerical columns using `StandardScaler`.
* **Model Training & Tuning:** Evaluated multiple models including Logistic Regression, Decision Tree, Random Forest, and Support Vector Machine (SVM), optimized using `RandomizedSearchCV`.
* **Evaluation Metrics:** Assessed performance using Accuracy, Precision, Recall, and F1-Score.

## Tech Stack
* Python
* Pandas, NumPy
* Scikit-Learn
* Matplotlib / Seaborn
